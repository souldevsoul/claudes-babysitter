### G1. COV1: crawl every static app route, linked or not (prepare). Cards: ga1ipn, d6p4gh, spdonv, gm21xv, 2b9nt9

**Where:** `playwright/prepare.mjs`.

**Why it is needed.** `crawl()` starts from `cfg.routes || ["/"]` plus `authRoutes`. The route templates it reads from the repo (`templateOf` on `git ls-files`) are used only to prioritise dynamic routes. A static page that nothing links to is never opened, so every existing check misses it. Two examples from this run:
- `/admin` (`app/(admin)/admin/page.tsx`). An anonymous GET answered 200; see e0894fe.
- `/docs/api`.

**Rule:**
1. After the link crawl, every static template from the repo that has not been visited is enqueued.
   - Static means no `[`.
   - Route groups `(x)` are stripped.
   - `api/`, `route.ts`, `_` folders, `crawl.exclude` and `forbiddenPages` are skipped.
2. Each is opened signed out, and once per role.
3. The rendered checks then run on every route that answers 200 and is not a redirect to the login page. This includes 1.11 logoHome, which already reports "logo links to /admin, not the home page" (soft) and covers ga1ipn and d6p4gh.
4. `crawl.json` gets `unlinked: [...]`, the routes that only the repo knew.

**Bad fixture:** a repo with
- `app/page.tsx` → `<a href="/pricing">`
- `app/pricing/page.tsx`
- `app/(admin)/admin/page.tsx` → `<aside><a href="/admin"><b>KINDRED</b></a><a href="/admin">Overview</a></aside><h1>Bureau</h1><p>Users: 42</p>`

  Expected: `routes.json` contains `/admin` (`unlinked`), and layout.spec's 1.11 reports `page logo links to /admin`.

**Good fixture:** same, but the admin logo has `href="/"`. `/admin` is still crawled, and 1.11 is quiet.

**Look-alikes (quiet):**
- `app/api/x/route.ts` is never enqueued.
- `app/(auth)/login/page.tsx` is already linked, so it is not duplicated.
- A page that redirects an anonymous visitor to `/login` is recorded as protected, not as a public route (same as today).

### G15. 2.18 (new): a rounded box does not scroll itself (rendered every state + static ESLint). Card: 5k8emt

**Why it is needed.** Headless Chromium uses 2 px overlay scrollbars, so the defect never shows in a screenshot. A classic 17 px scrollbar track is painted straight across the right-hand corner arcs (commit 2cceadf).

**Rule:**
- **Rendered:** an element is a hard finding when all of these hold:
  - its computed `border-radius` is ≥ 8 px on a right-hand corner;
  - `overflow-y` is `auto` or `scroll`;
  - it really scrolls (`scrollHeight > clientHeight + 1`);
  - it sets neither `scrollbar-width: none` nor `scrollbar-gutter: stable` with `overflow: clip` on an outer box.
  
  It is measured in every opened dialog / sheet / card of the state run. Report: `the opened card scrolls on its own rounded box (20 px): a desktop scrollbar draws across both right corners — keep the radius on an outer box that clips and scroll an inner one`.
- **Static (`ui/no-radius-on-scroller`):**
  - a className holding both `rounded-*` (other than `rounded-none`) and `overflow-(y-)?(auto|scroll)`;
  - or a CSS rule setting both `border-radius` and `overflow(-y)?: (auto|scroll)` on one selector.

**Bad fixture:** `<div role="dialog" style="border-radius:20px;overflow-y:auto;max-height:300px"><div style="height:900px">…</div></div>`

**Good fixture:** `<div role="dialog" style="border-radius:20px;overflow:hidden"><div style="overflow-y:auto;max-height:300px"><div style="height:900px">…</div></div></div>`

**Look-alikes (quiet):**
- A rounded `overflow-y:auto` box whose content fits (it does not scroll).
- A rounded scroller with `scrollbar-width:none`.
- A rounded-left-only sidebar (`rounded-l-xl`) that scrolls; its right corners are square on purpose.

### G16. 2.17 (new): a panel does not scroll sideways over nothing (rendered, every route and state). Card: 1zetde

**Why it is needed.** vaul's drag filler `::after` (1198 px) plus `overflow-y-auto` made the 599 px order drawer scroll to 1797 px (commit f273c0c). 2.1 measures the page and 2.14 / 2.10 treat scrollers as fine, so neither reports it.

### G18. 2.14b: an icon is shown in full (rendered, every route, width and state). Card: x099su

**Rule:** for each visible `svg` or `img` of 64 px or less (icons):
- (a) **Clipped by an ancestor.** Hard when its box is cut by ≥ 1 px by an ancestor that clips (overflow hidden/clip, not a scroller), the same test 2.14 applies to glyphs.
- (b) **Squeezed.** Hard when its rendered width is smaller than its declared width by ≥ 1 px:
  - the declared width is the `width` attribute, or the computed `width` style before flex resolution, read via `el.style` / the matched width class;

**Look-alikes (quiet):**
